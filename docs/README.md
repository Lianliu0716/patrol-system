## 題目演變

值得一提的是前兩份的差異。最初的方向是用 YOLO 訓練模型辨識巡邏點的物件，後來改成樣板比對加 GPS 的雙重驗證 —— 在手機端即時執行、不需要訓練資料、也不需要為每個新巡邏點重新標註與訓練，對實際部署較可行。這個取捨的過程記錄在 2/09 與 2/13 兩份提案的差異裡。
